Multi tasking is of Two Types
1.Process based Multi tasking.
	
	Process based multitasking can be achieved at OS.
	In process based multitasking every process independent   
	to each other.
	Every Process will occupy individual memory.

2.Thread based multi tasking.
	Thread based multi tasking can be achieved at programming.
	In Thread based multi tasking , for entire threads there
	will be only memory.
	
	import threading
	import time

	Thread is a light weight process.
	Executing multiple threads at time is called thread based
	multi tasking or 	multithreading.
